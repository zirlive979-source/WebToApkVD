V1

WebToApkVD ngubah website jadi APK Android asli pakai native WebView. Pilih mode online (APK cuma shell, load situs live) atau offline (tampilan situs dibundle ke dalam APK). Proses build beneran jalan di GitHub Actions — bukan simulasi, hasilnya APK ter-sign yang bisa langsung diinstal.
